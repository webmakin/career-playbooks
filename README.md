# Career Playbooks

> **A series of practice-first playbooks for becoming a senior engineer, manager, or AI leader — every chapter produces a graded artifact.**

This repo holds a growing collection of role-specific playbooks. Each playbook is structured the same way: a multi-chapter book with an 11-section anatomy per chapter, executable drills, worked examples, failure-mode postmortems, self-assessment rubrics, and interview-question banks. **Every chapter ships a graded artifact you can carry into an interview.**

## Quickstart

```bash
# 1. Install mdbook (Rust toolchain; brew install mdbook on macOS)
brew install mdbook

# 2. Build the site
cd ~/Downloads/career-playbooks
mdbook build

# 3. Serve locally with hot-reload
mdbook serve --port 3000 --hostname 127.0.0.1
# → open http://localhost:3000/

# 4. Verify the skeleton
python3 _shared/tools/rubric_linter.py --all          # all chapter stubs PASS
python3 _shared/tools/score_drill.py --fixture        # rubric scorer demo
python3 _shared/tools/cost_estimator.py --fixture     # LLM cost model demo
python3 _shared/tools/publish.py --all                # mirror role chapters into book/src/
```

## Conventions

Every playbook in this repo follows the same contracts. They live in `_shared/` and are versioned together:

- **[chapter-anatomy.md](_shared/chapter-anatomy.md)** — the 11-section template every chapter must follow.
- **[rubric-spec.md](_shared/rubric-spec.md)** — the 5-dimension self-assessment rubric format.
- **[figure-style-guide.md](_shared/figure-style-guide.md)** — Mermaid conventions and diagram rules.

When `_shared/` changes, every playbook must be re-verified. See `STATUS.md` for per-playbook chapter status.

## Bootstrap a new playbook (30 minutes)

Each new playbook (Engineering Director, VP Engineering, etc.) follows the same bootstrap. The skill at `~/.hermes/skills/software-development/leadership-playbook-authoring/SKILL.md` has the full recipe. Quick version:

1. Create `<role>-playbook/{chapters,exercises,resources,templates,diagrams}/`.
2. Add the role to `SLUG_MAP` in `_shared/tools/publish.py` (dir name → URL slug).
3. Create `book/src/<slug>/README.md` (placeholder).
4. Add the role to `SUMMARY.md` as a stub chapter.
5. Run `publish.py --all` (the new role will be skipped until chapters exist).
6. Run `mdbook build` to verify.
