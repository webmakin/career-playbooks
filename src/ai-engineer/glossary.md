### AI Features

- **AIE (AI Engineer):** Hybrid engineer who owns LLM integration, prompt engineering, and AI feature delivery.
- **4-pillar AIE model:** LLM integration + prompt engineering + AI feature delivery + AI observability.
- **AI features per quarter:** Target AI feature output (3+).
- **Latency p99:** 99th percentile latency (target <200ms).
- **Cost per request:** Average cost per request (target <$0.01).

### LLM Stack

- **LLM stack:** Model + serving + orchestration + observability.
- **3-decision templates:** OpenAI + Anthropic + open-source.
- **Vendor lock-in:** 100% dependency on a single LLM vendor.
- **Eval harness:** Test cases + metrics + LLM-as-judge + ground truth.
- **5-criterion stack bar:** Latency + cost + quality + reliability + safety.

### Prompt Engineering

- **Prompt template:** Reusable template with variables + examples + tests.
- **3-prompt templates:** Zero-shot + few-shot + chain-of-thought.
- **Prompt versioning:** Git-tracked prompt versions.
- **Prompt eval:** Automated eval harness for prompt quality.

### RAG & Agents

- **RAG (Retrieval-Augmented Generation):** Chunking + embedding + retrieval + generation.
- **3-RAG templates:** Naive + hybrid + agentic.
- **Agent:** Planning + tool use + memory + reflection.
- **3-agent templates:** Single + multi + hierarchical.

### Observability & Eval

- **4-observability pillars:** Logging + tracing + metrics + eval.
- **3-observability templates:** Logs + traces + dashboards.
- **LLM-as-judge:** LLM evaluates LLM output.
- **Production eval:** Eval on production logs.

### Safety

- **4-safety pillars:** Input filter + output filter + jailbreak detection + PII detection.
- **3-safety templates:** Regex + classifier + LLM-as-judge.
- **Jailbreak success rate:** Successful jailbreak attempts / total (target <1%).

### Production

- **LLM serving:** Batched + streaming + cached.
- **4-serving pillars:** Latency + throughput + cost + quality.
- **Fine-tuning:** LoRA + full + RLHF.

### Career & Comp

- **5-level AIE ladder:** AIE1 (Junior) -> AIE2 (Mid) -> AIE3 (Senior) -> AIE4 (Staff) -> AIE5 (Principal).
- **5-dim AIE rubric:** LLM features + prompt engineering + observability + collaboration + impact.
- **12-month dev plan:** Per-AIE development plan.

### Governance & Risk

- **4 risk pillars:** Feature + eval + safety + cost.
- **3 risk tiers:** HIGH + MEDIUM + LOW.
- **4 compliance pillars:** AI safety + data privacy + bias + transparency.
