# VP of Engineering Playbook

> **Coming soon**

A practice-first guide for VPs of Engineering. Covers portfolio strategy, board reporting, multi-org coordination, M&A integration, and the path from Director to VP.

## What this will be

When complete, this playbook follows the same contract as the [AI Engineering Director playbook](../ai-eng-director/README.md):

- Multi-chapter structure (planned: ~25-30 chapters)
- 11-section chapter anatomy per chapter
- Per-chapter exercise bundles (drill + template + worked-example + README)
- 5 named failure modes per chapter
- Self-assessment rubric (5 dimensions, 25 points, pass at 18+)
- Portfolio artifact for every chapter (interview evidence)
- Concrete numbers verified against `_shared/tools/cost_estimator.py` and other tools
