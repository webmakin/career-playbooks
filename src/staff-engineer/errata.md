# Staff Engineer Playbook

## Errata & Known Issues

> **Honest accounting of what's incomplete, what might be wrong, and what the author would change in v2.**

### What's incomplete

- **Chapter 28 (Engineering Methodology Appendix) is an appendix.** It introduces the 4-method model + 3 quality attributes but doesn't go deep on each method. The SE should pair this with engineering-methodology-specific reading.

- **No case studies of named SE transitions.** The chapters describe what good SEs do, but don't include specific named case studies. v2 would add 5-10 named case studies.

- **No coverage of remote + distributed engineering orgs.** All chapters assume in-person. v2 would add a chapter on remote + distributed engineering.

### What might be wrong

- **The 4-pillar SE model is one SE's framework.** Some SEs prefer 3-pillar (technical direction + architecture + influence) or 5-pillar (with engineering excellence as a separate pillar). The book uses 4-pillar because it's the most common.

- **The 3 cross-team projects per quarter target.** Some SEs ship 1 cross-team project per quarter, others ship 10+. The book uses 3 because it's the median for an SE at a 200-person company.

- **Some Mermaid diagrams have visual artifacts.** mdBook's Mermaid renderer occasionally has issues with complex diagrams.

### What the author would change in v2

- **Add a chapter on AI/ML engineering practices.** Most modern engineering orgs are AI/ML-first. v2 would have a dedicated chapter on AI engineering practices.
- **Add a chapter on platform engineering.** Many SEs own platform teams. v2 would cover platform engineering specifically.
- **Add case studies.** 5-10 named case studies with permission.
- **Tighten the 5-criterion bar.** The book uses different 5-criterion bars in different chapters. v2 would standardize.

### Versioning
