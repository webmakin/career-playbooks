## 1. Epigraph

_The Staff Engineer is a category change. The IC-to-SE transition requires 4 mindset shifts: from project delivery to technical direction, from team scope to cross-team scope, from code review to architecture review, and from personal output to engineering excellence._

---

## 2. Problem

You are a Staff Engineer at acme-corp. The engineering director has just told you: "the ic-to-staff-engineer category change. 30-day timeline."

This chapter tells you the 4 mental models, 3 frameworks, and 5-criterion quality bar.

**Decision in one sentence:** _IC-to-SE is a 4-mindset-shift category change (project -> direction, team -> cross-team, code review -> architecture review, personal output -> engineering excellence) with 3-month transition and 5-criterion bar._

---

## 3. Why Staff Engineers Fail Here

Five named failure modes of Staff Engineers whose the ic-to-staff-engineer category change produced zero results.

- **The Same-as-Senior Failure.** SE works like senior. No principal influence.
- **The Project-Thinking Failure.** Thinks in projects, not direction.
- **The Team-Only Failure.** Only works in 1 team.
- **The Code-Review-Only Failure.** Only code reviews. No architecture.
- **The Personal-Output Failure.** Owns personal output. No excellence.

---

## 4. Mental Models

Four mental models that compress the ic-to-staff-engineer category change.

**mental model 1: The 4 Mindset Shifts:** 4 shifts: project -> direction, team -> cross-team, code review -> architecture review, personal output -> excellence.

**mental model 2: The 3-Month Transition:** 3 months: month 1 observe, month 2 first architecture, month 3 first direction.

**mental model 3: The 5-Criterion Transition Bar:** 5 criteria: direction + architecture + influence + mentorship + excellence.

**mental model 4: The SE vs Senior Comparison:** Side-by-side comparison.

## 8. Failure Mode Postmortem

An IC at a 200-person company tried to become an SE. Worked like a senior. 0 cross-team work. 0 architecture decisions. The VP Eng said: 'You're still an IC.'

What the first Staff Engineer missed: the ic-to-staff-engineer category change is a system. The first SE had no system. The second SE had 4 mental models + 3 frameworks + 5 criteria. The system is the leverage.

The lesson: the SE who has the system has the ic-to-staff-engineer category change. The SE who has no system has the failure mode.
