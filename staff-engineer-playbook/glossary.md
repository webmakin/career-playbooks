### Technical Direction

- **SE (Staff Engineer):** Principal IC who owns technical direction, cross-team architecture, and engineering influence.
- **4-pillar SE model:** Technical direction + cross-team architecture + engineering influence + technical mentorship.
- **Cross-team projects per quarter:** Target cross-team project output (3+).
- **Architecture decisions per quarter:** Target architecture decision output (3+).
- **5-criterion direction bar:** Direction + architecture + influence + mentorship + excellence.

### Architecture

- **4-architecture-pillar framework:** Requirements + trade-offs + decisions + validation.
- **3-design templates:** Monolith + microservices + event-driven.
- **ADR (Architecture Decision Record):** Documented architecture decision with trade-offs.
- **System design:** Requirements + trade-offs + patterns + scaling.
- **Tech debt:** Catalog + prioritize + paydown + prevent.

### Quality & Reliability

- **4-quality-pillar framework:** Review + standards + testing + documentation.
- **3-review templates:** PR + design + architecture.
- **SLO:** Service Level Objective (e.g., 99.9% availability).
- **MTTR:** Mean Time To Recovery (target <2 hours SEV1).

### Tooling & DX

- **4-tooling-pillar framework:** CI/CD + observability + testing + IDE.
- **3-tooling templates:** Build + deploy + monitor.
- **DX (Developer Experience):** Engineering productivity + satisfaction.

### Production

- **Production ops:** Deployment + monitoring + incident + post-mortem.
- **Migration:** Strangler + parallel + big-bang.
- **Reliability:** SLOs + monitoring + alerting + incident response.

### Mentorship

- **4-mentorship-pillar framework:** 1:1 + code review + pairing + career.
- **3-mentorship templates:** Junior + senior + staff-track.
- **Mentee outcomes:** Promotion + skill development + retention.

### Stakeholders & Influence

- **4 stakeholder groups:** VP Eng + EM + senior IC + customers.
- **3 influence patterns:** Data + framework + relationship.
- **5-criterion influence bar:** Specific + aligned + timed + owned + reusable.

### Career & Comp

- **5-level SE ladder:** SE1 (Junior) -> SE2 (Mid) -> SE3 (Senior) -> SE4 (Staff) -> SE5 (Principal).
- **5-dim SE rubric:** Architecture + tech direction + quality + influence + impact.
- **12-month dev plan:** Per-SE development plan.

### Governance & Risk

- **4 risk pillars:** Architecture + reliability + migration + tech debt.
- **3 risk tiers:** HIGH + MEDIUM + LOW.
- **4 compliance pillars:** Security + privacy + data governance + code provenance.
