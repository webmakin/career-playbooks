# ML Researcher Playbook

## Glossary

### Research Output

- **MLR (ML Researcher):** Research-trained hybrid who owns research methodology, experimental design, and paper submission pipeline.
- **4-pillar MLR model:** Research methodology + experimental design + paper pipeline + research direction.
- **Papers per year:** Target publication output (2+ at top venues).
- **Co-authors:** Cross-team and academic collaboration.
- **Industry voice:** Keynotes, panels, and talks.

### Experiments & Methodology

- **Hypothesis:** Falsifiable claim that drives experimental design.
- **4-design-pillar framework:** Hypothesis + variables + controls + metrics.
- **3 design templates:** Ablation + comparison + scaling.
- **Reproducibility:** 100% of experiments reproducible with documented code + data + hyperparams.
- **Baseline:** Comparison point (e.g., Transformer, public benchmark).

### Paper Writing

- **5-criterion paper bar:** Novel + rigorous + reproducible + impactful + well-written.
- **Paper ADR:** Architecture Decision Record for paper submissions.
- **Rebuttal:** Response to reviewer comments.
- **Camera-ready:** Final paper version after acceptance.

### Open Source

- **OSS release:** Library + benchmark + checkpoint releases.
- **4-OSS-pillar framework:** Code + docs + tests + license.
- **3 release types:** Library + benchmark + checkpoint.
- **5-criterion OSS bar:** Documented + tested + licensed + adoptable + maintained.

### Production

- **3-stage model lifecycle:** Research -> staging -> production.
- **4-inference-pillar framework:** Latency + throughput + cost + accuracy.
- **3 serving templates:** Batched + streaming + quantized.
- **Production parity:** Research accuracy == production accuracy (within 1%).

### Career & Comp

- **5-level RS ladder:** RS1 (Junior) -> RS2 (Mid) -> RS3 (Senior) -> RS4 (Staff) -> RS5 (Principal).
- **5-dim research rubric:** Publication + research depth + engineering + collaboration + impact.
- **12-month dev plan:** Per-MLR development plan.

### Stakeholders & Influence

- **4 stakeholder groups:** Senior scientist + collaborators + eng + customers.
- **3 influence patterns:** Data + framework + relationship.
- **5-criterion influence bar:** Specific + aligned + timed + owned + reusable.

### Governance & Risk

- **4 risk pillars:** Paper + experiment + collaboration + compliance.
- **3 risk tiers:** HIGH + MEDIUM + LOW.
- **4 compliance pillars:** IRB + data + AI safety + open-source.
- **4-phase crisis playbook:** Detect + contain + resolve + communicate.

### Methodology

- **4-method research model:** Empirical + theoretical + benchmark + ablation.
- **3 quality attributes:** Rigor + reproducibility + novelty.
- **5-criterion methodology bar:** Per methodology.
